## Project

Nytta AI marketing site — a static single-page site (`index.html`, `assets/style.css`, `assets/main.js`). No build step; deployed as-is.

## Git workflow

- Work directly on `main`. Do not create feature branches for changes to this repo.
- Commit and push directly to `main` when a change is ready.
- Do not open pull requests for routine changes — `main` is the deploy branch.
